DELIカップ ビュッフェ｜LP＋WEB注文デモ

index.html : 販促LP（利用シーン→注文方法→6プラン→メイン）
order.html : WEB注文デモ（プラン選択・メイン・4名以上の人数・日時・受取方法・連絡先）
style.css / order.js / images : 両ページに必要なファイル

1. このフォルダを丸ごと展開して index.html を開いてください。
2. LPの各プランから注文デモに遷移します。
3. 公開する場合、フォルダ内の全ファイルをまとめてNetlify Drop等にアップロードします。

注意
- プラン名・料理内容・写真・価格・予約期限・配送可否・時間枠はいずれも試作用です。
- 画像は生成したコンセプト画像であり、実際にあいあい弁当が提供する料理の写真ではありません。
- 注文フォームはブラウザ内の動作デモです。送信・保存・決済・通知は行いません。
- 本番化には確定価格・人数別数量仕様・配送条件・注文受付バックエンド・個人情報管理・決済サービス等が必要です。
